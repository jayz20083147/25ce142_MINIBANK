# MiniBank - Java Practical Series

A comprehensive Java banking system implementation demonstrating core to advanced Object-Oriented Programming and Java concepts through structured practical exercises.

## Overview

The project is structured into progressive practical modules (Practical-01 through Practical-14):

- **Practical-01**: Basic CLI menu, records, and control flow.
- **Practical-02**: Account model, encapsulation, and balance operations.
- **Practical-03**: Customer and Account associations.
- **Practical-04**: Command parser, transaction types, and statement formatting.
- **Practical-05**: Inheritance hierarchy (SavingsAccount, CurrentAccount, FixedDepositAccount).
- **Practical-06**: Interfaces and polymorphism (Transactable, InterestBearing, Premium, WithdrawRule).
- **Practical-07**: Custom annotations and reflection validation (`@Id`, `@Positive`, `@MaxLength`).
- **Practical-08**: Custom banking exception hierarchy (`BankException`, `InsufficientFundsException`, etc.).
- **Practical-09**: Multithreading and concurrent transactions (`AccountWorker`).
- **Practical-10**: Producer-Consumer concurrency model (`TransactionBuffer`, `TransactionProcessor`).
- **Practical-11**: File I/O, transaction logging, state persistence, and report generation.
- **Practical-12**: Generic collections and repository storage (`AccountStore`).
- **Practical-13**: Generic Repository pattern with annotation metadata.
- **Practical-14**: Full-featured Capstone Banking Service with unit tests and logging.

## Prerequisites

- Java Development Kit (JDK 17+)
